# ADR-001: レンダリングエンジンとして PixiJS v8 を採用する

- **ステータス**: 承認済み
- **決定日**: 2026-03-29
- **補足**: 背景透過（`backgroundAlpha: 0`）の要件は [ADR-003](./ADR-003-chroma-key-background.md) でクロマキーに変更した。PixiJS v8 の採用は有効

---

## コンテキスト

アバターのリアルタイムレンダリングには以下の要件がある。

- 複数テクスチャパーツの階層的な描画（Scene Graph）
- 毎フレームのアフィン変換（回転・スケール・位置）更新
- 背景透過（`backgroundAlpha: 0`）
- M1 MacBook Air / Webブラウザ上で 30fps 以上を維持

レンダリングエンジンの選択肢を評価する必要があった。

---

## 決定

レンダリングエンジンとして **PixiJS v8** を採用する。

---

## 結果

### ポジティブ

- WebGPU / WebGL2 のどちらもバックエンドとしてサポートしており、M1 Macの GPU性能を活かせる
- `Container` / `Sprite` による Scene Graph が標準機能として提供されており、パーツ階層管理が容易
- `Application.ticker` (requestAnimationFrame ベース) で安定したレンダリングループを実現できる
- `backgroundAlpha: 0` オプションで透明キャンバスを簡単に実現できる
- TypeScript ファーストの型定義が整備されている
- 2Dゲーム・Live2D 代替用途でのコミュニティ実績が豊富

### ネガティブ

- v7 → v8 でAPIの破壊的変更が多く、古いサンプルコードをそのまま流用できない
- WebGPUバックエンドはまだ実験的な部分があり、ブラウザ対応状況に注意が必要
- 3D表現（頭部の立体的な傾き）は苦手であり、2Dスプライトで近似表現するしかない

---

## 検討した代替案

| 案                 | 概要                   | 棄却理由                                                        |
| ------------------ | ---------------------- | --------------------------------------------------------------- |
| Three.js           | WebGL/3D汎用ライブラリ | 2Dスプライト管理が冗長。本プロジェクトの用途にオーバースペック  |
| Konva.js           | Canvas 2D ライブラリ   | GPU アクセラレーションなし。パフォーマンスが不十分になる可能性  |
| 素の Canvas 2D API | 依存ゼロ               | Scene Graph・テクスチャ管理を全自前実装する必要があり工数が過大 |
| Babylon.js         | WebGL/3Dエンジン       | Three.js と同様にオーバースペック。セットアップコストも高い     |
